  Behavioral (4): suspicious_patterns, contains_sudo, contains_pipe, contains_redirect

NEW ENGINEERED FEATURES (6):
  1. command_complexity_score
     └─ Captures: How sophisticated/evasive commands are
     └─ Formula: (avg_length / max_length) × entropy
     └─ Range: 0.0 - 1.0 (higher = more complex)
     └─ Malicious pattern: 0.3-0.8 (complex evasion)
     └─ Benign pattern: <0.1 (simple routine)

  2. suspicion_intensity
     └─ Captures: Concentration of malicious-looking commands
     └─ Formula: suspicious_patterns / total_commands
     └─ Range: 0.0 - 1.0 (0% to 100% suspicious)
     └─ Malicious pattern: 0.3-0.8 (high density of suspicion)
     └─ Benign pattern: <0.1 (mostly normal)

  3. entropy_variance
     └─ Captures: Inconsistency between process and command behavior
     └─ Formula: |process_entropy - cmd_entropy|
     └─ Range: 0.0 - ∞ (higher = more divergent)
     └─ Malicious pattern: >1.0 (inconsistent = suspicious)
     └─ Benign pattern: <0.5 (consistent = normal)

  4. process_concentration
     └─ Captures: How many different processes are used (reuse indicator)
     └─ Formula: 1 / (unique_processes + 1)
     └─ Range: 0.0 - 1.0 (higher = fewer processes)
     └─ Malicious pattern: 0.5-1.0 (reuses few processes)
     └─ Benign pattern: 0.0-0.3 (uses many processes)

  5. command_concentration
     └─ Captures: How many different commands are used (targeting)
     └─ Formula: 1 / (unique_commands + 1)
     └─ Range: 0.0 - 1.0 (higher = fewer commands)
     └─ Malicious pattern: 0.3-0.8 (repeats attack commands)
     └─ Benign pattern: 0.0-0.2 (diverse commands)

  6. attack_vector_score
     └─ Captures: Multi-faceted attack indicator
     └─ Formula: 0.4×suspicion_intensity + 0.2×contains_sudo + 0.2×(contains_pipe+redirect)
     └─          + 0.1×(1-process_concentration) + 0.1×(1-command_concentration)
     └─ Range: 0.0 - 1.0 (probability of attack)
     └─ Malicious pattern: 0.4-1.0 (strong attack signals)
     └─ Benign pattern: 0.0-0.3 (minimal indicators)
